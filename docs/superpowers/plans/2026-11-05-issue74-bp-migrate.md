# cortex-bp-migrate live-contract fix (issue #74) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Make `skills/cortex-bp-migrate` and every toolkit skill/resource name only tools and routed commands the live Cortex MCP server exposes, make reparent-in-place the default migration flow, and remove the referencer-losing rename swap.

**Issue:** https://github.com/etelyatn/cortex-toolkit/issues/74 (reporter etelyatn). Depends on UnrealCortex #119 contract (CortexSandbox issue 119): `blueprint.list type/exclude_types`, `blueprint.graph_metrics`, `graph.search_nodes` optional filters/graph_name, `analyze_for_migration sections`, widget enumeration fix.

**Tech Stack:** Markdown skills/resources, Python stdlib unittest, Git Bash shell suites.

## Decisions

- **D1 Lint source of truth.** Committed snapshot `tests/fixtures/cortex-mcp-surface.json`: `{exposed_tools:[...], domains:{<domain>:[commands...]}, facade_commands:{core:[get_status,get_capabilities,schema_status,get_data_catalog,switch_editor,batch]}, legacy_tools:[...]}`. Generated by `scripts/sync-cortex-mcp-surface.py --plugin <UnrealCortex dir>`: domains from `MCP/tests/fixtures/capabilities_cache_full.json`; exposed tools by running the plugin server's tool registration (`cortex_mcp.server._register_explicit_tools` with a recording registrar and the fixture capabilities, via `uv run` in the plugin MCP project; no editor); legacy tools = names in `MCP/tests/fixtures/mcp_tool_signature_snapshot.json` not exposed. `--check` mode compares without writing.
- **D2 Lint test** `tests/test_cortex_tool_names.py` (stdlib unittest) over `skills/**/*.md`, `resources/**/*.md`, `templates/**/*.md`, `README.md`:
  - `<domain>_cmd(command="x"` / `<domain>_cmd("x"` → x must be in that domain's commands (plus core facade commands);
  - backticked `` `domain.command` `` where domain is a known domain → command must exist;
  - backticked identifier or `identifier(` equal to a legacy tool name → fail;
  - drift: when `CORTEX_PLUGIN_DIR` or the sibling `../Plugins/UnrealCortex` exists, the snapshot must equal a fresh `--check` generation (skipped with reason otherwise).
  Failure messages list `file:line token → expected`.
- **D3 Default flow = reparent in place.** Original Blueprint is reparented and cleaned with `blueprint_cmd` `reparent` / `cleanup_migration` / `remove_*` / `graph_cmd apply_patch` on the original asset. Before mutating: `blueprint.duplicate` → `BP_Name_Backup` as a read-only snapshot for `compare_blueprints` verification (duplicate does not touch referencers). Rollback: unsaved → `core_cmd reload_asset` (discard); saved → revert via source control (documented), backup used for comparison only. The rename swap (`rename BP→Backup`, `fixup_redirectors`, `rename Migration→BP`) is removed everywhere, with a short "why not" note (engine `RenameAssets` rewrites referencers to the renamed asset). No copy-based swap remains, so no referencer test is required.
- **D4 Graph reads.** Replace `graph_list_nodes`/`graph_get_node`/scope-limitation text with: `graph_cmd list_graphs {include_subgraphs:true}` (kinds incl. macro/delegate, `subgraph_path`), `graph_cmd get_subgraph {graph_name, subgraph_path?}`, paged inventory `graph_cmd search_nodes {asset_path, graph_name}` (no filter, cursor paging), `blueprint_cmd graph_metrics` for reachable logic budgets. Delegate graphs are readable, not mutable.
- **D5 Widgets.** Analysis widgets come from `analyze_for_migration`; on plugin builds without the #119 fix (empty `widgets` for a Widget Blueprint), read the tree with `umg_cmd get_tree` — stated as an explicit guard.
- **D6 Project-wide audit.** `--audit` without a Blueprint path (or with a folder) documents: `blueprint_cmd list {path, type|exclude_types}` → per asset `graph_metrics` + `analyze_for_migration {sections:[...]}` → aggregated report. The one-call export arrives with CortexSandbox #120 and will be synced then.
- **D7 Resource paths.** Phase guides are referenced as plugin-root `resources/…`; remove references to non-existent `docs/plans/...` and `docs/unreal-coding-standards.md` (or mark the latter as a project-side file if it exists in the consuming project).
- **D8 #119 reference sync.** `resources/mcp-tool-reference.md`: list params/rows, graph_metrics, search_nodes semantics, get_struct_schema paths, analyze sections; remove nonexistent graph `list_nodes`/`get_node`/`compact`.
